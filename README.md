# 위탁 협의가 자동 참고 매칭 (구글시트 버전)

'위탁장부' 시트의 과거 이력에서, '협의중리스트' 시트 안에 아직 받아갈금액이 안 정해진(=지금
협의 중인) 행마다 같은 브랜드+같은 디자인 과거 사례를 찾아서 참고 제안가를 자동으로 채워주는
스크립트. GitHub Actions로 3시간마다 자동 실행되도록 만들어져 있음.

지금 형이 매일 쓰는 장부는 마이크로소프트 365(엑셀 온라인)에 있어서, 이 자동화가 작동하려면
먼저 그 장부를 구글시트로 옮겨야 함 (형이 "구글시트로 옮길 수 있음"으로 확인해줬음).

## 0. 장부를 구글시트로 옮기기

1. 마이크로소프트 365에서 지금 쓰는 장부 파일을 다운로드 (엑셀 온라인 → 파일 → 다른 이름으로
   저장 → 사본 다운로드, `.xlsx`로)
2. https://drive.google.com 접속 (`ziconi0817@gmail.com` 계정으로) → **새로 만들기** →
   **파일 업로드** → 방금 다운로드한 xlsx 업로드
3. 업로드된 파일 더블클릭 → 위쪽에 "Google Sheets로 열기" 뜨면 그걸로 열기. 또는 업로드된
   파일 우클릭 → **연결 앱** → **Google Sheets**
4. 그러면 진짜 구글시트(`.gsheet`)로 하나 더 생기는데, **이제부터는 형이 이 구글시트에
   직접 입력**해야 라이브 데이터가 최신 상태로 유지됨 (마이크로소프트365 파일은 더 이상
   업데이트 안 하고 이 구글시트가 "진짜"가 되는 것)
5. 그 구글시트를 열어서 주소창 URL을 봐두기 — `https://docs.google.com/spreadsheets/d/`
   바로 뒤, `/edit`  바로 앞의 긴 문자열이 **SPREADSHEET_ID** (4단계에서 필요)

> 참고: 형 구글드라이브 확인해보니 `더비위탁_매입장부 - 위탁장부`라는 구글시트가 이미 있는데,
> 2월 5일에 한 번 만들어지고 그 뒤로 업데이트가 안 된 옛날 스냅샷이라 이건 라이브로 못 씀.
> 새로 위 순서대로 지금 쓰는 최신 파일을 옮겨야 함.

## 1. Google Sheets API 활성화 + 서비스 계정 만들기

1. https://console.cloud.google.com 접속 (같은 구글 계정으로 로그인)
2. 상단에서 새 프로젝트 만들기 (이름 아무거나, 예: "derby-price-match")
3. 좌측 메뉴 **API 및 서비스** → **라이브러리** → "Google Sheets API" 검색 → **사용 설정**
4. 좌측 메뉴 **API 및 서비스** → **사용자 인증 정보** → **사용자 인증 정보 만들기** →
   **서비스 계정** 선택 → 이름 아무거나 입력 → 만들고 계속하기 → 완료
5. 방금 만든 서비스 계정 클릭 → **키** 탭 → **키 추가** → **새 키 만들기** → **JSON** 선택
   → 자동으로 JSON 파일이 다운로드됨 (이 파일 안의 내용을 4단계에서 통째로 사용함)

## 2. 구글시트에 서비스 계정 공유하기

1. 다운로드된 JSON 파일을 텍스트 편집기로 열어서 `"client_email"` 값을 복사
   (`...@....iam.gserviceaccount.com` 형태의 이메일)
2. 0단계에서 만든 구글시트 열기 → 우측 상단 **공유** → 방금 복사한 이메일을 붙여넣고
   **편집자(Editor)** 권한으로 공유

## 3. GitHub 리포지토리 만들기

1. GitHub에서 새 리포지토리 생성 (Private 추천 — 회사 상품/가격 데이터를 다루는 자동화라서)
2. 이 폴더 안의 파일들을 그대로 그 리포지토리에 올리기 (`price_match_gsheets.py`,
   `requirements.txt`, `.github/workflows/schedule.yml`, 이 `README.md`)

## 4. GitHub Secrets 등록

리포지토리 → **Settings** → **Secrets and variables** → **Actions** →
**New repository secret** 로 아래 두 개 등록:

- `GOOGLE_SERVICE_ACCOUNT_JSON` → 1단계에서 다운로드한 JSON 파일을 텍스트 편집기로 열어서
  **전체 내용을 그대로** 복사해서 붙여넣기 (중괄호 `{ }` 부터 끝까지 전부)
- `SPREADSHEET_ID` → 0단계 5번에서 메모해둔 그 긴 문자열

## 5. 확인

- 리포지토리 **Actions** 탭에서 워크플로우가 보이는지 확인
- **Run workflow** 버튼으로 즉시 한 번 수동 실행해서 로그 확인 — 정상이면
  "이번 실행에서 처리한 행: N건" 로그가 찍히고, 구글시트의 협의중리스트에
  `제안가(자동)_받아갈금액` / `제안가(자동)_참고사례` 두 컬럼이 자동으로 생기면서 채워짐
- 이후로는 3시간마다 자동 실행됨. 형이 매일 새 물건을 협의중리스트에 입력하면, 다음 자동
  실행 때 그 행도 채워짐 (사장님/대표님 승인 필요 없이 참고용 숫자만 자동으로 뜨는 것 — 최종
  가격 결정은 여전히 두 분이 하는 거고, 이건 그 판단을 도와주는 참고자료)

## 매칭 로직 요약

1. 협의중리스트에서 `받아갈금액`이 비어있고 `브랜드`+`디자인`이 채워진 행 중,
   `제안가(자동)_받아갈금액`이 아직 비어있는 행만 최대 30건(`MAX_ITEMS_PER_RUN`) 처리
2. 위탁장부 전체에서 같은 브랜드 + 같은 디자인(완전 일치)인 과거 사례(받아갈금액이 실제로
   있는 것만)를 전부 찾음 — 특이사항까지 똑같을 필요는 없음
3. 그중 **사이즈까지 같은 사례를 최우선**으로, 그다음 최근 날짜 순으로 정렬해서 상위 5건을
   참고사례 문구로 정리
4. 제안 숫자(`제안가(자동)_받아갈금액`)는 그 1순위 사례(사이즈 동일 + 최신, 없으면 브랜드+
   디자인만 일치하는 것 중 최신)의 받아갈금액
5. 매칭 없으면 "이전 유사거래 없음"이라고만 표시, 숫자 컬럼은 비워둠
6. `받아갈금액`, `브랜드`, `디자인` 등 기존 컬럼은 절대 안 건드리고, 새로 만든 두 컬럼 외에는
   아무것도 안 씀. 이미 제안가가 채워진 행이나 이미 협의완료(받아갈금액 있음)된 행은 다시
   안 건드림 (재실행해도 중복 작업 없음)

## 필요하면 바꿀 수 있는 것

- 실행 주기: `.github/workflows/schedule.yml`의 `cron: '0 */3 * * *'`
- 한 번에 처리하는 최대 건수: `price_match_gsheets.py`의 `MAX_ITEMS_PER_RUN`
- 참고사례 표시 개수(지금 5건): `build_reference()`의 `max_cases`
- 시트/헤더 위치가 다르면: `HIST_SHEET_NAME`, `NEG_SHEET_NAME`, `NEG_HEADER_ROW` 환경변수로 조정
